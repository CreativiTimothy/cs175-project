# Final Report Guide

## 1. Project Summary

Motivate next-day prediction difficulty, market noise, regime changes, and the always-up baseline.

## 2. System Architecture and Algorithms

Include an architecture figure showing data acquisition, preprocessing, window construction, chronological splitting, normalization, training, evaluation, ranking, and backtesting. Describe FNN, logistic regression, always-up, LSTM, and return regression. Include advantages and disadvantages.

## 3. Evaluation

This should be the largest section. Report exact date ranges, symbols, sample counts, split dates, hyperparameters, random seeds, metrics, calibration, confusion matrix, ROC curve, ablations, backtest assumptions, transaction costs, and SPY comparison. Distinguish historical backtest from short live paper trading.

## 4. References and Resources

Cite course slides, Alpaca documentation, PyTorch documentation, scikit-learn documentation, papers, code sources, and external images.
